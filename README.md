# オフラスシステム ナレッジベース

## 📚 概要

このリポジトリは、**オフラスシステム** の統合的なナレッジベースです。

システムに携わるすべての人（転入者、保守担当者）が参照できる、実用的で信頼性の高い情報源として機能します。
