# オフラスシステム よくある質問（FAQ）

## ❓ よくある質問

初心者が最初に質問する内容をまとめています。疑問が解決しない場合は、より詳細な仕様書を参照するか、GitHub Discussions で質問してください。

---

## 📖 システム全般

### Q1. オフラスシステムって何ですか？

**A:**

オフラスシステムは、**石油製品の精製・供給プロセス全体を一元管理する統合情報システム** です。

**主な役割**:
- 📊 オーダー（受注）から実績記録までの全プロセス管理
- 🔄 複数の製油所・倉庫間でのデータ同期
- 📈 品質・実績データの一元管理
- 🛡️ セキュアで安定した運用

詳しくは → [システム概要](./overview.md)

---

### Q2. 誰が使うシステムですか？

**A:**

オフラスシステムを使う人は、大きく分けて **3つのグループ** です：

1. **現場作業者**
   - オーダー情報確認
   - 実績入力
   - 品質検査データ入力

2. **計画・管理者**
   - 生産計画立案
   - スケジュール調整
   - 進捗監視

3. **システム管理者**
   - マスタ管理
   - ユーザー管理
   - システム保守

### Q3. システムにログインできません。どうしたらいい？

**A:**

以下の順番で確認してください：

```
1️⃣ 基本確認
   ✓ ユーザー ID とパスワードが正しいか再確認
   ✓ Caps Lock は off になっているか
   ✓ インターネット接続は大丈夫か

2️⃣ ブラウザ確認
   ✓ ブラウザキャッシュをクリア（Ctrl+Shift+Delete）
   ✓ 別のブラウザで試す（Chrome, Firefox など）
   ✓ シークレットモードで試す

3️⃣ それでもダメな場合
   ✓ システム管理者に連絡
   ✓ アカウントが有効か確認をリクエスト
```

詳しくは → [トラブルシューティング - ログイン](./troubleshooting.md#ログインできない)

### Q4. ネットワークが切れてしまったようです。どうなりますか？

**A:**

入力中のデータ状況によって異なります：

- ✅ **保存済みのデータ**：安全です。ネットワーク復旧後も存在します。
- ❌ **保存前のデータ**：失われる可能性があります。定期的に「保存」ボタンをクリックしてください。

**予防策**:
- 定期的に保存ボタンをクリック（特に長文入力時）
- 「保存中...」メッセージが「保存完了」に変わるまで待つ
- ネットワークランプが点灯していることを確認

## 🔐 ユーザー・権限

### Q5. 自分の権限で何ができるか知りたい。

**A:**

システムにログイン後、以下の手順で確認できます：

```
1. 左上の [プロフィール] をクリック
2. [ユーザー権限] を選択
3. 自分の権限一覧が表示されます
```

**主な権限例**:
- オーダ入力：オーダーを新規登録できる
- 実績入力：実績データを入力できる
- 品質登録：検査データを入力できる
- 承認：オーダーや計画を承認できる

権限に疑問がある場合は、上司またはシステム管理者に相談してください。

### Q6. パスワードを忘れてしまいました。

**A:**

**自分でリセット可能な場合**:
1. ログイン画面で [パスワードを忘れた] をクリック
2. メールアドレスを入力
3. パスワードリセットメールが届きます
4. メール内のリンクから新しいパスワードを設定

**リセットメールが来ない場合**:
- システム管理者に連絡
- ユーザー ID またはメールアドレスを伝える
- パスワード リセットを依頼

## 📋 オーダ管理

### Q7. オーダーを登録するにはどうしたらいい？

**A:**

基本的な手順：

```
1. メニューから [オーダ管理] → [新規オーダ] をクリック

2. 必須項目を入力：
   ✓ オーダ ID（またはシステムが自動採番）
   ✓ 顧客名（マスタから選択）
   ✓ 製品種別（マスタから選択）
   ✓ 数量
   ✓ 希望納期
   ✓ その他の条件

3. [保存] ボタンをクリック

4. 確認画面で内容を確認

5. [確定] をクリック（確定権限が必要）
```

**注意**:
- 「保存」と「確定」は異なります。確定して初めてシステムに反映されます。
- 顧客や製品がマスタに登録されていない場合は、先にマスタを登録してください。

詳しくは → [機能仕様書 - オーダ管理](./specifications-guide.md#オーダ管理)

---

### Q8. オーダーを間違えて登録してしまった。キャンセルできますか？

**A:**

**オーダのステータスによります**：

| ステータス | キャンセル可能 | 方法 |
|-----------|-------|------|
| 草案（下書き） | ✅ Yes | [削除] ボタン |
| 確定 | ✅ Yes | [キャンセル] ボタン |
| 計画中 | ⚠️ 条件付き | 計画をキャンセルしてから |
| 生産中 | ❌ No | 上司に相談 |

**キャンセル手順**:
1. オーダを検索・開く
2. [ステータス] を確認
3. [キャンセル] ボタンが表示されている場合はクリック
4. 理由を入力
5. [確認] をクリック

**ステータス変更できない場合**:
- 権限がない可能性があります
- 上司またはシステム管理者に相談

---

### Q9. 既存のオーダーを検索する方法は？

**A:**

**複数の検索方法があります**：

1. **簡易検索**
   - メニュー上部の検索ボックスにオーダ ID を入力
   - [検索] ボタンをクリック

2. **詳細検索**
   - [オーダ管理] → [詳細検索] をクリック
   - 以下の条件で検索可能：
     * オーダ ID
     * 顧客名
     * 登録日期間
     * ステータス
     * 納期期間

3. **フィルター**
   - オーダ一覧画面で [フィルター] をクリック
   - 条件を選択（例：「今月のオーダ」など）

**Tips**: よく検索する条件は「お気に入り」に登録できます。

## 📊 実績管理

### Q10. 実績を入力するにはどうしたらいい？

**A:**

**実績入力の前提条件**:
- ✅ オーダが登録・確定されている
- ✅ 作業計画が立案されている
- ✅ 品質検査が完了している

**実績入力手順**:

```
1. メニューから [実績管理] をクリック

2. 対応するオーダを検索

3. [実績入力] をクリック

4. 以下の情報を入力：
   ✓ 完成日時
   ✓ 実績数量
   ✓ 消費材料
   ✓ 実作業時間
   ✓ 作業者情報

5. [保存] → [確定] をクリック
```

**注意**:
- 数量エラーがないか確認（オーダ数量と一致するか）
- 材料原価が自動計算されます
- 確定後は修正に権限が必要です

詳しくは → [機能仕様書 - 実績管理](./specifications-guide.md#実績管理)

---

### Q11. 実績入力後に間違いに気づきました。修正できますか？

**A:**

**ステータスによります**：

| ステータス | 修正可能 | 方法 |
|-----------|--------|------|
| 草案 | ✅ Yes | [編集] ボタン |
| 確定（当日） | ✅ Yes | 上司承認で修正可能 |
| 確定（翌日以降） | ❌ No | 修正伝票を作成 |

**修正手順**:
1. 実績レコードを開く
2. [編集] ボタンをクリック（権限がある場合）
3. データを修正
4. [保存] → [確定] をクリック

**修正できない場合**:
- 修正伝票（差分入力）を作成
- 上司に報告

## 🔬 品質管理

### Q12. 品質検査データはどこに入力するのですか？

**A:**

**品質検査データ入力**：

```
1. メニューから [品質管理] をクリック

2. [検査入力] を選択

3. 検査対象のオーダを検索

4. [検査項目] タブで以下を入力：
   ✓ 検査日時
   ✓ 検査者
   ✓ 各検査項目の測定値
   ✓ 合格/不合格判定

5. [保存] → [確定] をクリック
```

**検査項目は自動表示**：
- 製品種別と仕様に基づいて必須検査項目が自動表示されます
- すべての項目を入力する必要があります

**不合格の場合**:
- 理由を入力
- 上司に報告
- 再検査プロセスが開始

---

### Q13. 検査基準値がわかりません。どこで確認できますか？

**A:**

**基準値の確認方法**：

1. **画面上での確認**
   - 品質管理画面の各検査項目欄に「基準値」が表示
   - 例：「温度：150-180℃」
   - マウスホバーで詳細が表示

2. **仕様書での確認**
   - 製品マスタ → 品質基準タブ
   - または製品カタログ

3. **マスタ管理での確認**
   - [マスタ管理] → [品質基準マスタ]
   - 製品を選択して基準値を確認

**わからない場合**：
- 上司に相談
- 品質管理チームに問い合わせ

## 📞 システムの問題

### Q14. 画面の読み込みがすごく遅いです。

**A:**

**以下を順番に試してください**：

```
1️⃣ ブラウザ関連
   ✓ ブラウザキャッシュをクリア（Ctrl+Shift+Delete）
   ✓ 開いているタブを減らす
   ✓ ブラウザを再起動

2️⃣ ネットワーク関連
   ✓ インターネット速度をテスト
   ✓ WiFi から有線LAN に変更
   ✓ 別のネットワークから接続

3️⃣ パソコン関連
   ✓ タスクマネージャーを開く（Ctrl+Shift+Esc）
   ✓ CPU / メモリ使用率を確認
   ✓ 不要なアプリを終了
   ✓ パソコンを再起動

4️⃣ それでもダメな場合
   → システム管理者に報告
      （ブラウザ、OS、実行時刻を伝える）
```

もし複数ユーザーが同じ遅さを感じている場合は、サーバー側の問題の可能性があります。

詳しくは → [トラブルシューティング - パフォーマンス](./troubleshooting.md#パフォーマンス関連)

### Q15. "Database connection error" というエラーが出ました。

**A:**

**この エラーは、オフラスシステムがデータベースに接続できていません。**

**自分でできる対策**：

```
1️⃣ 一時的な問題の可能性
   ✓ 5分待つ
   ✓ ページをリロード（F5キー）
   ✓ 再度ログイン

2️⃣ ネットワーク確認
   ✓ インターネット接続を確認
   ✓ VPN接続を確認（VPN使用の場合）
   ✓ 別のシステムにアクセス可能か確認

3️⃣ ブラウザ確認
   ✓ ブラウザキャッシュをクリア
   ✓ 別のブラウザで試す
   ✓ ブラウザを再起動
```

**それでもダメな場合**：
- システム管理者に報告
- 「Database connection error」と伝える
- 発生時刻を伝える

詳しくは → [トラブルシューティング - DB接続エラー](./troubleshooting.md#dbコネクション-エラー)

### Q17. 不具合を報告したい。

**A:**

**不具合報告の流れ**：

```
1. 情報を整理
   ✓ 何が起きたか（具体的に）
   ✓ いつ起きたか（日時）
   ✓ どの機能か
   ✓ 自分でした対応

2. スクリーンショット撮影
   ✓ エラーメッセージが見える画面
   ✓ 異常が起きた操作画面

3. 報告
   ✓ GitHub Issues で報告
   ✓ または Discussions で質問
   ✓ または 直接 管理者に報告

4. 連絡待ち
   ✓ 確認・対応を待つ
   ✓ 連絡があれば対応
```

**報告に含めるべき情報** → [トラブルシューティング - 報告時情報](./troubleshooting.md#報告時に含めるべき情報)
