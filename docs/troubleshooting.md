## 接続・ログイン関連

### ❌ ログインできない

**症状**: ユーザー名/パスワードは正しいのにログインできない

**原因と解決策**:
```
1. アカウント状態確認
   ✓ アカウントが有効化されているか確認
   ✓ パスワードの有効期限を確認
   → 管理者に問い合わせ

2. ブラウザキャッシュクリア
   ✓ Ctrl+Shift+Delete でブラウザキャッシュを削除
   ✓ 異なるブラウザで試す
   ✓ シークレットモードで試す

3. ネットワーク確認
   ✓ インターネット接続を確認
   ✓ ファイアウォール設定を確認
   ✓ VPN接続の確認

4. セッションタイムアウト
   ✓ しばらく時間をおいて再ログイン
   ✓ 複数タブで同時ログインしていないか確認
```

**参考資料**: `IOS20-OFL-SBM-T2-001_機能仕様書_システム共通_v1.1.docx`

---

### ❌ セッションが切れてしまう

**症状**: 作業中に突然ログアウトされる

**原因と解決策**:
```
1. セッションタイムアウト設定
   ✓ システム設定でタイムアウト時間を確認
   ✓ 適度に操作を行う（キーボード入力など）
   ✓ 長時間離席する場合はログアウトしておく

2. ネットワーク不安定性
   ✓ Wi-Fi接続を安定したものに変更
   ✓ 有線接続を試す
   ✓ 別のネットワークから接続

3. ブラウザ設定
   ✓ クッキーが有効になっているか確認
   ✓ 制限付きサイトリストを確認
   ✓ JavaScriptが有効になっているか確認
```

## データベース関連

### ❌ DBコネクション エラー

**症状**: "Database connection error" というメッセージが表示される

**原因と解決策**:
```
1. ネットワーク確認
   ✓ DBサーバーへの接続確認
   ✓ ファイアウォール ポート設定確認
   ✓ VPN接続を確認

2. DB サーバーステータス
   ✓ DBサーバーが起動しているか確認
   ✓ DBサーバーのリソース（CPU/メモリ）を確認
   ✓ DBサーバーのディスク容量を確認
   → 管理者に確認を依頼

3. キャッシュクリア
   ✓ ブラウザキャッシュを削除
   ✓ アプリケーションの再起動
   ✓ 5分待機後に再接続

4. コネクション数上限
   ✓ 他のユーザーの接続数を確認
   ✓ 不要な接続を切断
   ✓ 時間をずらして再接続
```

**予防��**:
- ✅ 業務終了時は必ずログアウト
- ✅ 長時間作業する場合は定期的にログアウト/ログイン
- ✅ 複数タブでの同時接続を避ける

---

### ❌ データが保存されない

**症状**: データを入力して保存しても反映されない

**原因と解決策**:
```
1. ネットワーク確認
   ✓ インターネット接続を確認
   ✓ 「送信中...」メッセージを確認（完了待ち）
   ✓ エラーメッセージの内容を確認

2. 権限確認
   ✓ その操作の権限があるか確認
   ✓ ステータス（確定/草案など）を確認
   ✓ 依存するマスタが設定されているか確認

3. 入力値チェック
   ✓ 必須項目が入力されているか確認
   ✓ 形式が正しいか確認（日付、金額など）
   ✓ 文字数制限を確認

4. ブラウザ更新
   ✓ F5キーで画面をリロード
   ✓ Ctrl+Shift+R でキャッシュをクリアしてリロード
   ✓ ブラウザの再起動
```

## パフォーマンス関連

### ❌ 画面の読み込みが遅い

**症状**: ページの読み込みに異常に時間がかかる

**原因と解決策**:
```
1. ネットワーク速度確認
   ✓ 他のシステムの応答速度を確認
   ✓ インターネット速度をテスト
   ✓ 別のネットワークから接続

2. ブラウザ最適化
   ✓ 開いているタブ数を減らす
   ✓ ブラウザキャッシュをクリア
   ✓ ブラウザの再起動
   ✓ 異なるブラウザで試す（Chrome, Firefox, Edge など）

3. PC リソース確認
   ✓ メモリ使用率を確認（タスクマネージャー）
   ✓ CPU使用率を確認
   ✓ ディスク容量を確認
   ✓ 不要なアプリケーションを終了

4. サーバーサイド確認
   ✓ 他のユーザーも同じ遅さを感じているか確認
   ✓ 別の機能で確認
   → 管理者に報告（ログ情報を含める）
```

**予防策**:
- ✅ 定期的にブラウザキャッシュをクリア
- ✅ 定期的にPCを再起動
- ✅ 業務終了時は不要なタブを閉じる

### ❌ 複数拠点間でデータが同期されない

**症状**: 本社で登録したデータが支社に反映されない

**原因と解決策**:
```
1. 通信接続確認
   ✓ 拠点間ネットワーク接続を確認
   ✓ VPN接続を確認

2. 同期スケジュール確認
   ✓ 同期間隔を確認
   ✓ 同期完了を待つ（通常5〜15分）
   ✓ 手動同期を実行

3. データ競合確認
   ✓ 同じデータを複数拠点で同時編集していないか
   ✓ 競合が発生していないか確認

4. ログ確認
   ✓ システムログで同期エラーを確認
   → 管理者に報告
```

## 📞 サポート情報

### エスカレーション判断フロー

```
問題発生
    ↓
  [自己解決可能？]
  ├─ YES → トラブルシューティング実施
  └─ NO → チーム内で相談
          ↓
      [チーム内で解決？]
      ├─ YES → 完了
      └─ NO → 保守担当者・システム管理者に報告
```

### 報告時に含めるべき情報

**問題報告の際は以下の情報を含めてください**:

```
1. 問題の概要
   - 何が発生したか（具体的に）
   - いつ発生したか（日時）
   - どの機能で発生したか

2. 環境情報
   - OS（Windows/Mac など）
   - ブラウザ種別とバージョン
   - アクセス方法（社内LAN/VPN など）

3. 再現手順
   - 問題を再現する具体的な手順

4. スクリーンショット
   - エラーメッセージが表示されている画面
   - 異常が見える操作画面

5. 既試事項
   - すでに試した対応方法
   - 結果どうだったか
```
